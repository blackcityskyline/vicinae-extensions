# Pomodoro

A focus and break timer with music: three YouTube live streams played through
`mpv` and `yt-dlp` with no browser and no ads, or offline ambient loops that
ship with the extension.

Port of [alessandrobelli/omarchy-pomodoro](https://github.com/alessandrobelli/omarchy-pomodoro)
v1.3.3, an Omarchy bar widget. The bar has no equivalent here, so the timer is a
`List`; the timer, the music and the state file are the same ideas.
`docs/audits/pomodoro.md` in the parent repository records what was measured and
what was dropped.

## Use

| Row | Action |
| --- | --- |
| Timer | `Enter` starts a focus, then pauses and resumes it |
| Timer | Skip ends the phase now; Reset abandons the session and stops the music |
| Music | `Enter` picks a source; picking the active one stops it |

The timer keeps running while the window is closed: a detached `sleep` shell
launches the hidden `advance` command at the deadline, which ends the phase,
plays the chime, sends the notification and starts or stops the music. The state
is `~/.local/share/vicinae/support/pomodoro/state.json`, so a reopened window
rejoins the session in progress. If that shell is gone — a killed process, a
machine that slept through the deadline — the window ends the phase itself the
first time it is opened.

## Preferences

| Preference | Default | Meaning |
| --- | --- | --- |
| Focus Minutes | 25 | Length of a focus, 1 to 600. |
| Break Minutes | 5 | Length of a break, 1 to 120. |
| Auto Continue | on | Start the next focus when a break ends. Off, the break ends paused. |
| Music on Break | off | Keep the music playing through a break. |
| Chime | on | Play the chime next to the notification. |
| Music Volume | 60 | mpv volume, 0 to 100. |
| Custom Channel | empty | One extra YouTube link offered next to the built-in ones. |

## Requirements

Linux. `mpv` with yt-dlp support (`mpv --list-options | grep ytdl`) plus `yt-dlp`
for the YouTube sources; nothing but `mpv` for the ambient ones, since the rain
loops are bundled and the two noise tracks are generated by mpv itself.
`pw-play` (PipeWire) or `paplay` plays the chime.

## Not verified

- the streams were resolved and decoded with `--ao=null` on 2026-11-08, and a
  real mpv was started from the extension with the rain loop audible, but a full
  focus with music that stops on the break was not sat through;
- Windows, macOS: Linux only, like the widget it ports.

## Development

```bash
npm install
npm run dev     # hot reload; logs to this terminal
npm run build   # type-check and install
npm test        # self-checks
```

Open it with:

```bash
vicinae 'vicinae://launch/@black/pomodoro/pomodoro'
```
