# Timer

Create and manage system-native background timers using natural language.

| Command | What it does |
| --- | --- |
| Start Timer | Start a new timer or select from presets. |

Based on [HarshNarayanJha/raycast-timer](https://github.com/HarshNarayanJha/raycast-timer). Forked from the Vicinae store version (`store.vicinae.timer`).
